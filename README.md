# Zancada

App de running que compite con Strava, con el carácter de Duolingo: te acompaña, premia tu constancia y te anima a correr con amigos.

Este repositorio contiene la **beta web** (carpeta raíz, publicada en GitHub Pages). Diseño y documentación de producto viven en la carpeta de trabajo del proyecto.

- `index.html` · la app completa
- `LEEME.md` · qué hace la beta, cómo probarla y limitaciones
